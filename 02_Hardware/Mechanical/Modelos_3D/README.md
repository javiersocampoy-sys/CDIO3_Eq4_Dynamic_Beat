# Modelos 3D

En esta carpeta se guardan los archivos 3D para imprimir las carcasas del proyecto Dynamic Beat. Aquí solo encontrarás:

- El diseño para las cajas de los 4 nodos periféricos (las cuatro son exactamente iguales).
- El diseño para la caja principal o nodo maestro, que tiene una forma diferente a las demás.
