# Archivos de la PCB

En esta carpeta se guardan todos los documentos finales para la fabricación y revisión de las placas de circuito del proyecto Dynamic Beat. Aquí encontrarás:

- **Archivos Gerber (.zip):** Los archivos técnicos comprimidos listos para mandar a fabricar las placas (PCB) mediante CNC o con un fabricante.
- **Planos en PDF:** Documentos de fácil lectura que muestran el diseño del circuito (esquemático) y el diseño físico con las pistas (ruteo) de los nodos.
