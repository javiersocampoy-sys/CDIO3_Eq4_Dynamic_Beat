## Librerías necesarias

- WiFi.h (incluida en el core ESP32)
- ESP32_NOW.h (incluida en el core ESP32)
- Pygame (Se utiliza para la interfaz grafica en python)
- Random (Se utiliza para generar números pseudoaleatorios. Se usa para elegir un elemento al azar de una lista, mezclar datos o introducir factores de probabilidad).
- Sys (Se utiliza para interactuar directamente con el intérprete de Python. Te permite, por ejemplo, leer los argumentos que se le pasan al script desde la consola de comandos o forzar el cierre del programa usando sys.exit()).
- Os (Se utiliza para interactuar con el sistema operativo en el que se está ejecutando Python. Es fundamental para tareas como crear, eliminar o mover carpetas, leer rutas de archivos y ejecutar comandos del sistema).
- Serial (Se utiliza para establecer comunicación a través de puertos serie. Es la librería estándar (conocida como pyserial) cuando necesitas que tu programa en Python se comunique con hardware externo, como placas Arduino, microcontroladores o sensores industriales).
